# 建议的意图 taxonomy 增量

只添加“用户主动表达的诉求”，不添加系统主动动作。

## 建议候选

```text
ACCOUNT.REGISTRATION_HELP
ACCOUNT.USAGE_GUIDE

PRODUCT.SELECTION_HELP
PRODUCT.COMPARE
PRODUCT.ASK_COMPATIBILITY

PROMOTION.QUERY
PROMOTION.ELIGIBILITY
PROMOTION.USAGE_HELP

PURCHASE.HOW_TO_BUY
PURCHASE.HESITATION
```

## 合并建议

- “适合老人/宿舍/小户型吗”统一为 `PRODUCT.SELECTION_HELP`，差异进入槽位。
- “哪个更好/这两个怎么选”统一为 `PRODUCT.COMPARE`。
- “有什么优惠”归 `PROMOTION.QUERY`。
- “我能不能用这个券”归 `PROMOTION.ELIGIBILITY`。
- “怎么领/怎么用优惠券”归 `PROMOTION.USAGE_HELP`。

## 禁止加入

```text
SYSTEM.PUSH_PROMOTION
SYSTEM.CLOSE_DEAL
SYSTEM.RECOMMEND_NOW
SYSTEM.START_ONBOARDING
```

这些是 NBA/Business Action，不是用户意图。
