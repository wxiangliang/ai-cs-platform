# 优先级与主动动作抑制

## 1. 固定优先级

```text
P0 安全、合规、身份保护、人工接管
P1 写操作确认门和用户明确拒绝
P2 用户当前明确诉求
P3 当前任务的必要补槽和结果
P4 用户主动请求的推荐、比较、活动说明
P5 系统主动的相关引导
P6 系统主动营销
P7 闲聊修饰
```

低优先级内容不得覆盖或延迟高优先级内容。

## 2. 全局抑制条件

以下情况强制 `NO_PROACTIVE_ACTION`：

- `active_task.intent` 属于退款、投诉、取消、数据删除等高风险流程；
- 当前 `CONFIRMING`；
- 已转人工或人工正在接管；
- 情绪为强负面；
- 用户本轮明确拒绝推荐、活动或继续引导；
- 最近达到展示频控；
- 商品、价格、库存或活动资格事实不可用；
- 当前消息为 `SOCIAL_ONLY` 且与商品/活动没有明确上下文关联；
- 当前回复已经包含复杂澄清，继续加入营销会造成认知负担。

## 3. 相关性约束

可选主动动作必须与以下至少一项直接相关：

- 当前业务意图；
- 当前 Playbook；
- 用户刚刚查看或询问的商品；
- 用户明确表达的购买目标；
- 已确认的客户旅程阶段。

不得仅因“有活动”就在任意会话中推广。

## 4. 频控

至少支持：

```text
per_customer_per_campaign
per_customer_per_day
conversation_max_proactive_actions
cooldown_after_rejection
permanent_opt_out
```

## 5. 冲突示例

| 当前状态 | 候选主动动作 | 结果 |
|---|---|---|
| 退款 COLLECTING | 推荐配件 | 抑制 |
| 投诉处理中 | 满减活动 | 抑制 |
| 查询价格完成 | 询问使用面积 | 允许，任务相关 |
| 选品完成 | 对比两个候选 | 允许 |
| SOCIAL_ONLY | 无关联活动 | 抑制 |
| 用户说“不用推荐了” | 任意推荐 | 冷却/退出 |
