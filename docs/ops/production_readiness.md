## 1. 并发与消息乱序

| 项 | 状态 | 说明 |
|---|---|---|
| 同会话并发轮次 | ✅ | dialog_state 乐观锁 version，冲突 409 + 失败轮独立事务留痕（Stage 03 v2，有测试） |
| 并发确认恰好执行一次 | ✅ | ActionExecutor `claim_for_execution` 条件 UPDATE 原子拿执行权（Stage 13，有并发测试） |
| 请求重复/双发 | ✅ | Idempotency-Key：在途锁 SET NX（并发双跑 409）+ body 指纹（422）+ 显式 commit 后写缓存 |
| 坐席并发抢单 | ✅ | claim 条件更新，仅一人成功（409） |
| 会话元数据并发写 | ✅ | metadata_json JSONB 合并 + CAS（post-stage-20） |
| WS 推送乱序 | ✅ | 设计语义即乱序安全：断线即弃、重连拉历史，**以 DB 为准推送只是加速** |
| 多 worker 负载/混沌验证 | ⏳ | **触发**：部署环境就绪。**动作**：多 worker 压测（同会话并发发消息、确认门并发、WS 广播跨进程）+ 记录 409 率基线 |
| HTTP 回复 vs WS 推送到达竞态 | ⏳ | 语义兜底已在（拉历史为准）；专项测试等真实前端联调期补 |

## 2. 离线指标 vs 线上质量

**立场（已写入多处文档的纪律）：明确不信任离线指标做上线判断。**

| 项 | 状态 | 说明 |
|---|---|---|
| 离线结论的局限被显式记录 | ✅ | SetFit 0.94 的四条局限（stage-27 文档）、Meta 合成集 LR=100% 定性"不构成上线依据"、全部阈值标"待标定" |
| 在线验证工具 | ✅ | 影子分歧率指标、quality_daily、CSAT/差评回流、hindsight 信号、A/B 框架、决策回放 |
| eval 门禁定位 | ✅ | 是**回归锁**（防改坏），不是质量预测器 |
| 离线↔线上标定关系 | ⏳ | **触发**：真实流量 2-4 周。**动作**：按 decision_source/margin 分层统计线上纠偏率（switch_guard/task_denied/差评）对照离线分布，产出标定报告后才允许调阈值 |

```text
□ MCP 真实对接完成幂等联调（同键重放不重复出单）——第 3 节

   ——APP_ENV=prod 硬门禁会拒绝启动缺项配置，这条有结构保证
□ 监控告警阈值标定（Stage 25 遗留 B3）+ 告警演练
□ 离线↔线上标定报告产出后才动阈值——第 2 节
```
