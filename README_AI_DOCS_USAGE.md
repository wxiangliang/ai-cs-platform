# ai-cs-platform 文档包使用说明

把本压缩包内容解压到项目根目录。

最终项目根目录应包含：

```text
AGENTS.md
docs/
```

以后让 Codex 写代码时，不要再贴一大段长需求，直接说：

```text
请先阅读根目录 AGENTS.md，
再阅读 docs/requirements/stage-01-foundation/01_foundation_framework.md。

本次只实现 Stage 01 基础框架。
严格按文档实现，不要超范围实现。
完成后说明新增文件、修改文件、启动方式和验证方式。
```

执行顺序：

```text
1. Stage 01：基础框架
2. Stage 02：聊天核心表
3. Stage 03：聊天主链路
```
